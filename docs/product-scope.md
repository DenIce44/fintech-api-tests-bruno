# Fintech API pilot

## Цель

Дать авторизованному клиенту возможность безопасно перевести деньги между двумя счетами в одной валюте и однозначно проверить результат операции.

## Основной пользователь

Клиент цифрового кошелька, прошедший требуемый уровень KYC и владеющий активным счётом.

## Ценность

Перевод либо выполняется один раз с согласованным изменением двух балансов, либо отклоняется без изменения денег.
