## REQ-POST-GET-001 — получение публикации по идентификатору

Endpoint `GET /posts/{id}` должен:

1. вернуть `200` и публикацию с запрошенным `id`, если запись существует;
2. вернуть `404`, если запись отсутствует;
3. не возвращать данные другой публикации при отсутствующем или некорректном ID;
4. возвращать JSON для успешного и ожидаемого негативного ответа.

````

Для учебного контракта добавьте acceptance criteria:

```markdown
### Acceptance criteria

- `id=1` возвращает первую существующую запись;
- `id=100` возвращает последнюю запись зафиксированного учебного набора;
- `id=101`, `id=0` и `id=abc` возвращают `404`;
- успешная запись содержит только `userId`, `id`, `title`, `body`;
- негативный ответ не содержит поля публикации;
- все пять вариантов выполняются одним data-driven запросом.
````
